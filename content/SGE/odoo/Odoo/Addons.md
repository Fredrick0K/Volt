This folder, located in ***Odoo17->Server -> odoo -> addons*** contains all the application that [[SGE/odoo/Odoo|Odoo]] has as default. Applications such as **Sales**, **CRM**, **Finance**. 
Every application is located in this folder, in its own folder, that contains everything that needs to work properly.
